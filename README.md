# format-note

将 Markdown 笔记格式化为项目统一样式的 Claude Code 技能（skill）。

## 功能

对目标 md 文件（或目录下所有 md 文件），按统一规范格式化：

- **标题层级**：`#` / `##` / `###` / `####` 前后各空一行
- **Q&A 格式**：`Q: ` 前缀、全文件连续编号、一级缩进（Tab）有序编号、二级及更深缩进（≥2 Tab）一律无序 `- `
- **强调**：尊重原文加粗，HTML 标签内 `<b>`/`<strong>` 保留原样
- **链接**：内部链接（`[[...]]`）别名前加 🔗，外部链接（`[文字](url)`）保持原样
- **图片**：`![[...]]` 上下各空一行；标题紧随链接（斜体），图片（组）之间空一行
- **块引用**：口诀 / 辨析 用粗体标签区分
- **缩进**：一级 Tab（有序），二级及更深 Tab+Tab（无序）

## 使用

输入文件路径格式化单个文件，输入目录路径格式化整个目录下的 md 文件。

## 文件

- `SKILL.md` — 技能定义与完整格式规范
- [`tools/`](tools/README.md) — 附带的独立脚本

> `tools/` 与 Skill 只是同放一处、一起版本管理的两个工具：运行脚本不影响 Skill，Skill 运行时也不会读取脚本。
