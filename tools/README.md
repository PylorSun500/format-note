# tools

笔记整理的辅助脚本。**只做机械改写，不做语义判断**——"参见互引"这类需要理解内容的活儿不在这里。

本目录与同仓库的 Skill 是**同放一处、一起版本管理**的两个独立工具：运行本脚本不影响 Skill，Skill 运行时也不会读取本脚本。

## renumber.py

把「已经初步排列、缩进关系正确，但序号顺序混乱」的 md 笔记一次性整理到位。

### 五条规则

| # | 规则 | 说明 |
| --- | --- | --- |
| ① | 补 `Q: ` 前缀 | 0 缩进的有序项（`1. xxx` → `1. Q: xxx`）；已有前缀则跳过 |
| ② | 序号连续化 | 全文件 `1..N`，不按标题重置 |
| ③ | 空行规则 | 标题 / Q&A 对 / 表格 / 代码块 / 图片 / 块引用 |
| ④ | 深层转无序 | 2 个及以上 Tab 的 `1. ` 一律转 `- `（1 Tab 保持有序） |
| ⑤ | 块引用标签加粗 | `> 辨析：…` → `> **辨析**：…`（口诀 / 辨析 / 参见） |

### 空行规则细则

- 标题（`#` ~ `####`）前后各一空行
- 相邻 Q&A 对之间一空行；Q 行与其 A 行之间**无**空行
- **例外**：A 是表格 / 代码块 / 图片时，这几样前后仍各一空行
- 块引用前后各一空行
- **同属标记组**（口诀 / 辨析 / 参见）的相邻块引用之间**无**空行；**无标签的引用块不参与合并**，原样保留
- 图片：**独立成行**则上下各一空行；**跟随编号**（`- ` `1. ` 之后）则上下都不空行
- 连续多个空行压成一个；开头不留空行；文件以恰好一个换行结尾

### 明确不做

- 链接 `🔗` 别名替换
- 图片标题 `<br>*…*` 的生成或改写
- **参见互引**（要写块标签并回链，属语义操作）

### 保真承诺

- **代码块内一律不动**（围栏 ``` / ~~~ 之间，含其中形如 `1. xxx` 的行）
- **Nerd Font 私有区字符**（`U+EC83`、`U+F0D7` 等）字节级保留
- 行尾风格（LF / CRLF）与文件权限保留
- **幂等**：整理过的文件再跑一遍报「无变化」，不会产生二次改动

### 安全机制

| 机制 | 说明 |
| --- | --- |
| 默认 dry-run | 不加 `--write` 绝不写盘，只打印统计 |
| 无变化则不碰 | 内容算出来和原来一样时，连文件 mtime 都不改 |
| 原子写 | 先写临时文件再 `os.replace` 替换，中途崩溃不留半截文件 |

> ⚠ 脚本**不做作用域保护**——传什么路径就处理什么路径。原始资料（如考纲原文引用）不要传进来。

### 用法

入口路径按你的项目布局而定：在本仓库里是 `tools/renumber.sh`，在软链接了本仓库的项目里是 `.claude/skills/format-note/tools/renumber.sh`。下面以本仓库为例：

```bash
./tools/renumber.sh "/绝对/路径/笔记.md"              # 预览统计
./tools/renumber.sh --diff  "/绝对/路径/笔记.md"      # 预览 + unified diff
./tools/renumber.sh --write "/绝对/路径/笔记.md"      # 落盘
./tools/renumber.sh --write "/绝对/路径/目录"         # 递归处理目录下所有 .md
./tools/renumber.sh --check "/绝对/路径"              # 只看退出码（0 = 无需改动，1 = 有改动）
```

### 参数

| 参数 | 作用 |
| --- | --- |
| `-w`, `--write` | 真正写入文件（默认只预览） |
| `--check` | 只检查；有需改动则退出码 1 |
| `--diff` | 预览时打印 unified diff |
| `--no-prefix` | 不补 `Q: ` 前缀 |
| `--no-flatten` | 不把深层有序编号转无序 |
| `--no-bold` | 不给块引用标签加粗 |
| `--no-blank` | 不整理空行 |
| `--no-merge-quotes` | 相邻块引用之间保留空行 |

### 输出示例

```
  path/to/笔记.md
    Q 前缀 +2    序号 8 项（改 5，重置 1）    深层转无序 3
    标签加粗 4    块引用合并 1    空行 新增 5 / 删除 5
```

## renumber.sh

`renumber.py` 的薄包装，省去关心 `python3` 与脚本自身路径；所有参数原样透传。

## 已知边界

- **独立成行的图片会"撑开"有序列表**。图片按 skill 规则上下各补一空行，视觉上把原本相邻的 `1.` / `2.` 拆成两段。若这不是想要的效果，需要改 `blank_pass` 里 `image` 的处理
- **顶层有序项一律视为 Q 行**。脚本无法区分"Q&A 的 Q"与"普通有序列表"，所以作用域必须由调用者把关
- **无标签的引用块只保留不动**。既不参与合并，也不会被加粗——归类为 口诀 / 辨析 / 参见 是 Skill 流程的活儿
